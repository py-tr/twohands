API

Everything on screen is an endpoint

Plain JSON over HTTP. Field codes are neutral: vote rows are OPT01 to OPT15 in printed order, the other lines by name (TOTAL, NULOS, ...).

{{ icon('api') }}Interactive reference (OpenAPI)
POST/api/gatetoken

Check a set of values against the paper's identities

Send the values you captured (any source: a model, a keyer, another system). Get back every identity, the failing fields, and the verdict. Needs the gate token (Authorization: Bearer).

{{ snippet('c1', "curl -s -X POST " ~ base ~ "/api/gate \\\n -H \"Authorization: Bearer $TWOHANDS_GATE_TOKEN\" -H \"Content-Type: application/json\" \\\n -d '{\"values\": {\"OPT01\": 61, \"OPT02\": 9, \"OPT07\": 113, \"NULOS\": 10, \"TOTAL\": 262}}'") }}
POST/api/live/{form}GET/api/jobs/{job}

Queue a live read on AMD and follow it

One live read runs at a time; a job waits in a short queue and reports its place, stages and elapsed time. The same events stream as server-sent events at /api/live/events/{job}.

{{ snippet('c2', "JOB=$(curl -s -X POST " ~ base ~ "/api/live/211294C0100 | python -c \"import sys,json; print(json.load(sys.stdin)['job'])\")\ncurl -s " ~ base ~ "/api/jobs/$JOB") }}

Without a key, read the stored verdict of any form: curl -s {{ base }}/api/form/211294C0100

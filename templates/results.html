Known limitation

One reader, one adjudicator, and recall only bounded.

Every disagreement was settled by one reviewer (an AI agent) on published crops, which anyone can re-check; a blind spot-check page lets a person do so without seeing any AI or capture value. Only disagreements were checked, so errors the model shares with the capture are not counted; recall is measured on only 7 fields. The shared endpoint paces reads to about 2 forms a minute; a national run needs a dedicated AMD endpoint.

Limitations we measured

The row-label check costs looks

{{ L.label_cost }} Each false alarm costs a person one look at a form that was read right; the check exists because a shifted row would otherwise keep the arithmetic true.

One read is not two independent reads

{{ L.harmonised }} Here the field (unused ballots) sits in no identity, so the gate accepted the form; it is one of the {{ H.acc_model_wrong }} wrong fields on accepted forms.

What the arithmetic can and cannot catch. Any single misread is caught, by words = digits where both are written or by a row sum or section identity; only an error that keeps every identity true passes (a compensating pair inside one sum, a misread of unused ballots, the one field in no identity, or words and digits harmonised in one call), and every wrong field on an accepted form ({{ H.acc_model_wrong }} for Gemma{% if n.T %}, {{ n.T.tiers.qwen.errors }} for Qwen{% endif %}) is unused ballots; separate reads, a second reader and the v2 rule close it (report, section 5).

One failure, shown honestly

The arithmetic gate has a blind spot: an error that keeps the arithmetic true.

Silent column shift on a rainfall ledger

Read as one image, {{ meta.model }} put Balcombe Gables' 1887 values under 1886, and so on along the row. Every shifted column still sums to its total, so the checksum accepted wrong cells: on that reader, {{ si.acc_col_cells - si.acc_col_exact }} of {{ si.acc_col_cells }} accepted cells were wrong ({{ si.cells|int }} cells read, {{ si.cell_acc }}% right overall). Zoomed tiles removed it ({{ lm.acc_cells - lm.acc_ok }} of {{ lm.acc_cells|int }} accepted cells wrong; spike, 40 sheets), but tiling is a mitigation, not a proof.

What we built because of it: on the tally sheet the reader must report the printed label it sees on every row, and the gate rejects a row whose label is not the one expected at that position, so a shifted or doubled row cannot pass. Its cost is measured above.

Sources: {{ si.source }}; spikes/ledger-rescue/README.md §4.

The safeguard: a person sees everything the paper cannot settle

Nothing is ever corrected silently. A form is accepted only when every identity the paper carries holds; everything else goes to the review desk with the failing field named and its crop, and a person types one value. If the paper itself is inconsistent, the person escalates it with a note.

Review desk now: {{ queue_n }} routed forms, {{ resolved }} handled.

Privacy is applied before anything else: the page is located by its corner marks and the column with officials' names and signatures is blacked out before the image is stored, sent to the model, or shown here. A page that cannot be located is not stored or sent at all; it goes to a person.

Framing: these are clerical capture checks on a settled 2024 count; the certified count is shown wherever it covers a field, and no party is compared with another and nothing is totalled across forms.
